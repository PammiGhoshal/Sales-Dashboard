# Excel Sales Dashboard

An interactive sales dashboard built in Microsoft Excel to analyze performance, track trends, and support data-driven decision-making.
## Features
- Sales by category analysis  
- Profit trends over time  
- State-wise sales distribution  
- Customer growth tracking  
- Top 5 profit-generating customers  
- Monthly sales insights
   ## Tools & Technologies
- Microsoft Excel (Pivot Tables, Charts, Slicers)
- ## Key Insights
- Identified top-performing categories  
- Observed seasonal sales trends  
- Highlighted high-value customers
